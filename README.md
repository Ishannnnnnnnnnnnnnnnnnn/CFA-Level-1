# CFA Level I // Braindump - Personal Study Operating System

A clean, high-performance personal study operating system designed specifically for CFA Level I candidates. Built to follow the exact Let Me Explain 2026/2027 curriculum structure with zero fluff and absolute tracking.

---

## ✨ Features

- **300-Hour Study Progress Tracker**: Real-time progress clock tracking target study hours vs actual logged sessions.
- **Dual Pomodoro & Stopwatch Timer**: Integrated timer with preset 25m/5m and 50m/10m focus cycles and auto-logging into the 300-hour study bank.
- **5 Coupled Navigation Hubs**:
  1. `Home`: Study space dashboard, metrics, progress bar, and up-next focus items.
  2. `Curriculum & LES`: Full 10-topic, module, and lesson hierarchy for 2026 and 2027 Let Me Explain coverage.
  3. `Practice & Review`: One-tap question logger, Wall of Shame mistake bank, Anki-style SRS flashcards, and Mock review debt tracker.
  4. `Weekly Plan`: Interactive 7-day schedule builder with custom task management.
  5. `Resources & Profile`: Prep links, builder profile, and JSON state export/import backups.
- **Collapsible Taskbar**: Compact 72px icon-only navigation strip with smooth transitions.
- **100% Native SF Pro Typography & Off-White/Sage Green Palette**: Premium Apple native typography and soft warm off-white (`#F7F9F6`) & sage green (`#E2EFE7` / `#1C3E2C`) reference styling.
- **Offline & Incognito Safe (`safeStorage`)**: Fail-safe local state persistence wrapped in defensive exception shields.

---

## 🛠 Tech Stack

- **Frontend**: HTML5, Tailwind CSS, Standalone Vanilla JavaScript ES6
- **Typography**: Apple Native SF Pro Display / SF Pro Text / SF Mono
- **Icons**: Custom 20px Vector SVG Icons
- **Storage**: LocalStorage with `safeStorage` exception shield
